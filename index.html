      From the terminal

      The same validation as a command, with Node.js 22 or later. Nothing to install: npx downloads it the first time.

      npx elpx-validator course.elpx

      Fail on warnings too (for CI)

      npx elpx-validator course.elpx --strict

      Full report as JSON, with the EDIA criteria

      npx elpx-validator course.elpx --json --edia
      Documentation

      Skill for AI assistants

      An Agent Skill that teaches assistants such as Claude Code or Copilot to validate .elpx packages and explain the findings.

      With npx skills

      npx skills add ateeducacion/elpx-validator

      With the GitHub CLI

      gh skill install ateeducacion/elpx-validator elpx-validator

      The skill uses the elpx-validator command line through npx.
